Visualization Information
Boundary Condition Types:
  • ■ INNER - Internal elements
  • ■ ADIABATIC - No heat transfer
  • ■ CONST_Q - Constant heat flux
  • ■ CONST_T - Constant temperature
  • ■ ACTUATOR_CONNECTED - Connected to actuator
  • ■ PLASTIC_COVERED - Plastic insulation
Additional Types:
  • ■ CONVECTIVE - Heat convection
  • ■ MAPPED - Mapped boundary
  • ■ NODE_CONNECTED - Connected to node network
  • ■ USERDEF_CONDUCTION - User-defined conduction
  • ■ USERDEF_CONVECTION - User-defined convection
Visualization Details:
  • Shows boundary conditions for the z=0 (bottom) surface of each region
  • Grid lines represent the finite element mesh
  • Colors indicate different boundary condition types
  • Region dimensions are shown in the title of each subplot
  • Red lines indicate adiabatic boundaries between elements
  • Legend has been removed from plots - boundary condition types are listed above
